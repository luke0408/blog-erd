# 비회원 세션과 환경 판정

관련 구조: [방문 세션](../erd.md#users), [브라우저 키](../erd.md#guest_browser_credentials), [분류 캐시](../erd.md#network_classifications), [판정 기록](../erd.md#guest_identifications). JSON 상세는 [데이터 계약](data-contracts.md#network-evidence)을 참조한다.

## 세션과 권한

- 방문마다 새 User와 난수 sessionKey를 발급한다. 지문·IP·별명으로 방문을 병합하지 않는다.
- 세션 토큰에는 sessionKey·tokenVersion·발급/만료·issuer/audience를 묶는다.
- 서비스는 서명·허용 알고리즘·만료·DB 버전·철회 상태를 검증한다. ID만으로 권한을 인정하지 않는다.
- 토큰 전달은 HttpOnly·Secure·SameSite 쿠키, 변경 요청 검증은 Origin/CSRF를 사용한다.
- 유휴 만료는 lastSeenAt, 절대 만료는 expiresAt으로 판단한다. TTL 값은 서버 설정의 책임이다.
- 같은 쿠키를 사용하는 여러 탭은 같은 방문이다. 브라우저 종료를 정확한 이탈 시각으로 간주하지 않는다.

환경별 방문 처리는 [비회원 판정](../erd.md#guest_identifications)을 따른다.
PERSONAL만 검증된 브라우저 키로 비민감 환경설정을 연결한다. SHARED·UNKNOWN은 추정 복구를 허용하지 않는다.

## 개인정보

토큰 원문·원본 IP·지문을 저장하지 않는다.
공개 응답에서는 sessionKey·콘텐츠 관리 키 해시를 제외한다.

## 키 범위와 수명

- 허용 scope는 PREFERENCES 하나다. 콘텐츠 관리·신고·개인 숨김 권한을 승계하지 않는다.
- 비밀 해시·scope·발급 시각·고정 만료는 불변이다. 만료는 발급 시각보다 늦어야 한다.
- version은 감소할 수 없고, 철회한 키는 되살릴 수 없다.
- SHARED·UNKNOWN 전환 시 키를 철회하고 브라우저 연결 없는 새 User를 발급한다.
- 논리 키 연결은 비밀 소유 증명이 아니다. 키 소유 검증은 서비스의 책임이다.

## 분류와 캐시

서비스는 신뢰 가능한 접속 IP를 공급자 분류로 변환한다.
클라이언트 제출 IP나 임의 X-Forwarded-For를 분류 근거로 사용하지 않는다.

| 항목 | 기준 |
| --- | --- |
| 캐시 키 | (ipDigest, provider) 복합 UNIQUE |
| 분류 값 | PERSONAL / SHARED / UNKNOWN |
| 익명 신호 | isAnonymous=true이면 PERSONAL 금지 |
| 보존 범위 | classifiedAt 이후 최대 1시간 |
| 판정 입력 | 만료되지 않고 미래 시각이 아닌 캐시 |
| 오류·누락 | UNKNOWN으로 처리 |

공급자·분류 정책·HMAC 키 버전은 providerVersion으로 구분한다.
만료 캐시를 안전한 환경의 근거로 재사용하지 않는다.
외부 공급자 호출은 DB 트랜잭션 밖에서 수행한다.

## 판정 원칙

User는 독립 방문 세션이다. PERSONAL은 검증된 브라우저 키의 비민감 환경설정 연결만 허용한다.
SHARED·UNKNOWN은 기존 방문이나 데이터를 추정해서 복구하지 않는다.
같은 쿠키를 공유하는 공공 기기의 실제 사용자를 이 구조만으로 구별할 수는 없다.

## 처리 순서

1. 서비스가 서명된 세션 쿠키와 서버 세션의 만료·철회 상태를 검증한다.
2. 신뢰 가능한 접속 IP의 분류 캐시를 확인한다. 실패·누락·만료는 UNKNOWN으로 처리한다.
3. 명시적 공유 모드와 위험 신호를 반영한다. SHARED·UNKNOWN을 PERSONAL로 승격하지 않는다.
4. 아래 조건표에 따라 현재 방문을 유지하거나 새 User를 발급한다.
5. GuestIdentification에 적용한 환경·처리 방법·사유·분류 증거를 기록한다.
6. 콘텐츠 수정·삭제는 환경과 관계없이 별도의 콘텐츠 관리 키를 검증한다.

## 환경별 방문 처리

| 환경·조건 | 방문 처리 | 브라우저 연결 |
| --- | --- | --- |
| PERSONAL, 유효 세션 | 현재 User 유지 | 검증된 연결만 유지 |
| PERSONAL, 새 방문과 유효 키 | 새 User 발급 | 비민감 환경설정만 연결 |
| PERSONAL, 키 유실·지문만 일치 | 새 User 발급 | 복구 없음 |
| SHARED·UNKNOWN, 유효 세션 | 서버 TTL 내 현재 User 유지 | 연결 없음 |
| 유휴 만료·공유 모드 전환·위험 변화 | 새 User 발급 | 연결 없음, 기존 키 철회 |
| 지문·사설 IP·시간만 일치 | 자동 복구 없음 | 연결 없음 |

브라우저 키·세션 토큰·콘텐츠 관리 키는 서로 다른 권한이다.
브라우저 키는 PREFERENCES만 연결하며 작성자·관리 키·신고·개인 숨김을 승계하지 않는다.
분류 공급자 장애나 선택 신호 누락은 일반 공개 조회를 막지 않지만 권한 검사를 생략하는 근거가 되지 않는다.

## 관계 제약과 서비스 책임

| 구분 | 기준 |
| --- | --- |
| 방문 바인딩 | browserCredentialId는 User의 브라우저 키와 일치 |
| 알려진 환경 | 유효한 NetworkClassification 참조 필요 |
| 캐시 미참조 | environment=UNKNOWN만 허용 |
| 브라우저 키 연결 | PERSONAL·유효한 캐시·미철회·미만료 키 필요 |
| 판정 증거 | 서비스가 서버 캐시 값으로 networkEvidence 구성 |
| 판정 시각 | 서비스가 서버 시각으로 receivedAt 기록, 클라이언트 제출값 무시 |
| 판정 보존 | UPDATE 금지, 최대 7일 보존, 만료 후 DELETE 허용 |
| 키 소유·세션 권한 | 서비스가 검증, 참조 ID나 digest로 대신하지 않음 |

물리 FK가 없으므로 참조 행의 존재부터 환경·키 유효성·캐시 만료·증거 내용의 행 간 규칙까지 서비스가 검증한다. 생성과 정리는 [관계 무결성](relation-integrity.md)의 공통 잠금·삭제 계약을 따른다.

SESSION_TOKEN은 현재 유효 방문, NEW_SESSION은 새 방문이다.
RECOVERY_CREDENTIAL은 새 방문에 환경설정을 연결하는 방법이며 기존 User의 복구가 아니다.

## 개인정보와 보존

선택 신호는 nullable이다. 신호가 없어도 방문을 발급할 수 있으며 수집 과정에서 브라우저 프라이버시 보호를 우회하지 않는다.
IP·지문 digest는 서비스·목적별 HMAC-SHA-256으로 생성하고 원문이나 단순 IP 해시는 저장하지 않는다.

클라이언트 시각은 참고값이며 유휴 판정은 서버 lastSeenAt과 수신 시각을 사용한다.
보존 만료는 자동 삭제 기능이 아니다. 만료된 판정 기록을 정리한 뒤 캐시의 참조 관계를 정리한다.
장기 보존 outbox에는 원본 IP·지문·digest·브라우저 비밀을 복사하지 않는다.

## 키·관측값 검증

브라우저 키 비밀은 서버 발급 256-bit 난수이며 DB에는 소문자 SHA-256 hex64만 저장한다. scope는 [JSON 계약](data-contracts.md#scopes)의 고정 배열만 허용한다. 토큰·키 원문은 쿠키 외 URL·이벤트·로그에 남기지 않는다.

토큰·브라우저 키 버전은 양수이며 서버 저장값과 대조한다. 방문 발급 시각·세션 바인딩은 불변이고 절대 만료는 필수다. 키 만료는 발급 시각보다 늦어야 하며 사용 시각 갱신으로 고정 만료를 늘리지 않는다. 키 소유 검증과 Origin/CSRF 검사는 참조 연결로 대체하지 않는다.

지문·접속 IP·사설 IP는 서비스·목적별 HMAC-SHA-256 hex64로 기록한다. WebRTC 실패·mDNS·미수집은 사설 IP 신호 NULL로 처리하며 수집을 강제하거나 프라이버시 보호를 우회하지 않는다. 클라이언트 시각은 참고값이며 유휴 초는 서버 lastSeenAt에서 계산한다.

분류 캐시가 갱신되어도 판정 증거는 바꾸지 않는다. 보존 만료는 자동 삭제가 아니며 만료 판정 기록을 먼저 정리하고 캐시의 논리 역참조를 공통 잠금 아래 확인한다. 동일인 추정으로 최초 작성자나 신고 세션을 다른 User에 연결하지 않는다.
